# Revisión integral de Biblia Verbo BV2026

## Alcance

- 66 libros
- 1.189 capítulos
- 31.084 versículos
- Identidad editorial final: Biblia Verbo BV2026
- Base principal de trabajo: el texto actual de Biblia Verbo BV2026, conservando
  todas las mejoras que ya contiene
- Procedencia histórica: Reina-Valera 1909 de dominio público
- Resultado esperado: una revisión completa, no una muestra ni un piloto

## Criterios de cierre

Un libro solo puede marcarse como cerrado cuando:

1. Todos sus capítulos fueron revisados versículo por versículo.
2. Se preservaron las mejoras válidas que ya contenía BV2026. RV1909 se consultó
   únicamente cuando fue necesario investigar una posible omisión, error de
   conversión o diferencia con la procedencia histórica.
3. Se corrigieron errores gramaticales, conversiones defectuosas de `vosotros`
   a `ustedes`, arcaísmos difíciles y nombres u ortografía desactualizados.
4. Los términos teológicos y las figuras literarias se conservaron o cambiaron
   mediante una decisión contextual, nunca mediante sustitución global ciega.
5. Las traducciones modernas se usaron solamente para comparar alternativas
   léxicas; su redacción no se copió como texto base.
6. Se verificaron negaciones, sujetos, género, número, tiempos verbales,
   referencias internas, nombres propios y estructura completa.
7. El JSON y las auditorías mecánicas pasaron sin errores.
8. El libro quedó señalado como candidato editorial, pendiente de aprobación
   humana final antes de llamarlo oficial.

## Estados

- `pendiente`: todavía no revisado de manera integral.
- `en revisión`: revisión versículo por versículo iniciada.
- `candidato`: revisión integral terminada y validada mecánicamente.
- `aprobado`: aprobado expresamente por Juan.

## Orden de trabajo

Se seguirá el orden canónico, cerrando cada libro antes de declarar terminado el
proyecto: Génesis, Éxodo, Levítico, Números, Deuteronomio y así sucesivamente
hasta Apocalipsis.
